# atlas

Personal project hub — a static dashboard linking to my projects, tools, and reference material. No build step, vanilla HTML/CSS/JS.

## Run locally

Open `index.html` in any browser.

## Pages

- **`index.html`** — main hub with Projects / AI Tools / Utilities sections.
- **`skills.html`** — searchable reference for installed Claude Code skills (finance/quant, code review, automation, etc.), with click-to-copy example prompts.

## Customize

Tiles and skills are defined as arrays at the bottom of each HTML file. Edit and reload.
