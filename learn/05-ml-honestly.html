Lesson 5 · The capstone

Machine learning, honestly.

Everything so far was preparation for this. ML can find patterns no human sees — and it can hallucinate patterns that were never there, with total confidence. The skill is telling the two apart.

~8 min · interactive · then we build it for real

ML in trading is just this: show a model the past as features (clues) and labels (answers), let it learn the mapping, then ask it about the future. Powerful. And the most dangerous tool in this whole course, because everything you learned about overfitting and leakage gets amplified — a model has thousands of knobs to fool itself with.

The terms, defined

features (X)
The inputs — the clues the model learns from. For BTC: past returns, volatility, RSI, momentum, volume. Every feature must use only past information, or you've leaked the future.
label (y)
The answer you're trying to predict. Here: did the next day close up or down? (a yes/no, so this is classification). If you predicted the actual return, that's regression.
training / test set
Training = the past the model learns from. Test = unseen data you grade it on. For time series these must be split in time — train on older, test on newer. Never shuffle.
baseline
The dumb benchmark you must beat. For up/down: a coin flip is 50%; "always guess up" might be 53% (markets drift up). A model at 52% is worse than guessing up. Accuracy means nothing without its baseline.
logistic regression / gradient boosting
Two workhorse models. Logistic regression is simple and hard to overfit — start here. Gradient boosting (XGBoost, LightGBM) is stronger and overfits more easily. Deep learning is overkill for this and overfits hardest; skip it.
cross-validation (and why it's a trap here)
The standard ML trick of shuffling data into folds. For time series it's wrong — shuffling lets the model train on the future to predict the past. Use time-ordered walk-forward instead (Lesson 3).
confusion matrix
The full scorecard: how often you said up and were right/wrong, and same for down. Accuracy hides things; a model that's 70% accurate but only ever says "up" has no skill.

Honest, this model is 52% — and it actually loses to the always-up baseline of 53%. That's a real, common, deflating result: no edge. Now flip the leak: accuracy jumps to 71% and looks incredible. But it's a ghost — one feature secretly used the next day's data. Ship it and you'd lose everything live. The beautiful number was the bug.

In ML trading, a believable result is a modest one. Spectacular accuracy is a confession that something leaked.

Engineer features (leakage-safe)
Past returns, rolling volatility, RSI, momentum — every one shifted so it uses only data available before the bar. ml/features.py
Make the label
Next-day direction: up or down. Aligned carefully so today's features predict tomorrow.
Split in time, never shuffle
Walk-forward: train on the past, test on the unseen future. The discipline from Lesson 3.
Train a simple model
Logistic regression first, then maybe gradient boosting. scikit-learn, no deep learning.
Judge it honestly
Out-of-sample accuracy vs both baselines. If it can't beat always-up, it has no edge — and that's a real, valuable answer.
We built this — here's what it actually found

The pipeline above is real code now (ml/train_direction.py). On daily BTC, both models scored ~49.5% out-of-sample — losing to the always-up baseline. No edge. Honest and deflating, exactly as this lesson warned.

Then we flipped the target to volatility (ml/predict_volatility.py): a simple persistence forecast hit +0.17 correlation out-of-sample — real, positive signal, because volatility clusters. Direction was noise; volatility was forecastable. And the dumb baseline beat the fancy model — the humbling result every quant meets. That contrast is the whole point.

Recap

ML is features in, predictions out — and a machine for fooling yourself unless you hold the line on baselines, time-ordered splits, and leak-hunting. You now have every concept you need: edge over prediction, risk over return, the backtest trap, honest sizing, and the suspicion that keeps you solvent. You're ready to build.
