# 🗂️ DHL "Ship Love. Ship Light." — Implementation Plan
### UOB Wonder Lab 2026 · campaign rollout
> The execution roadmap: how the idea becomes real across 36 ServicePoints in 3 months on ฿5M.
> Hero mechanic = the **PUT BOX buffet**. Source-of-truth for the Implementation Plan slide. **Rev:** 29 Jun 2026.

---

## 0. AT A GLANCE
- **Scope:** 36 ServicePoints · 3 months (13 weeks) · ฿5,000,000 cap · no celebrities.
- **Goal arc:** Build → Launch → Prove (Awareness → Participation → Proof).
- **Hero:** the **PUT BOX buffet** — customers bring their own packed box, sized by a W×L frame into S/M/L tiers, ship to ASEAN at a flat tier price. DHL subsidises the difference, **bounded by a hard cap.**

## 3. PHASE-BY-PHASE

### 🟡 Month 1 — Pre-launch (Build) · ฿1.0M (20%)
- Lock the **key message + Green-Claims wording** (GLEC/SAF; ban "carbon neutral/eco-friendly").
- Build **buffet station kits ×36** (W×L frame · timer · signage) + the QR/LINE booking flow + microsite.
- **Train branch staff** (run the buffet + GoGreen Plus one-liner).
- Stand up the **cap-tracking system** (quota can't be exceeded) + run the **baseline awareness survey**.
- **✅ Gate:** all 36 stations kitted + cap system live + staff trained *before* launch.

### 🟢 Month 2 — Launch (Run the buffet) · ฿2.75M (55%)
- Go live across **36 branches**; the **PUT BOX buffet** runs (ASEAN · size-capped · 1 per customer).
- Release the **SME film**; seed **#PutBoxInTheBox** UGC; targeted ads to Micro-SMEs + students.
- Screens/posters live; capture the "stuff the box" spectacle for social.
- **✅ Gate (Week 8):** participation on pace; **kill-switch** if the buffet quota is burning too fast.

### 🔵 Month 3 — Post-launch (Prove) · ฿1.25M (25%)
- Amplify the best UGC; retention nudges via LINE; close out the buffet quota.
- **Post survey + system-data pull + social sentiment + SME interviews.**
- **ROI readout:** awareness lift · participation · reach · CO₂ enabled.

## 7. PUT BOX BUFFET — operational setup (the hero)
- **Sizing:** a fixed **W×L frame** categorises the box into S/M/L (height free); bring-your-own packed box.
- **Tiers:** S ฿990 (1:00) · M ฿2,500 (1:30) · L ฿5,000 (2:30) — flat price to **ASEAN only**.
- **Bounds:** 1 box/customer · **hard cap (~4,800 boxes / while quota lasts)** → DHL exposure ≈ ฿2.4M, can't overrun.
- **Staff flow:** customer packs → staff sizes via the frame → real GoGreen Plus shipment → done.
