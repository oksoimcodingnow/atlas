## 2. PHASE-BY-PHASE

### 🟡 Month 1 — Pre-launch (Build) · ฿1.2M (24%)
- Lock the **key message + Green-Claims wording** (GLEC/SAF; ban "carbon neutral/eco-friendly").
- Build digital: QR/LINE CO₂ Tracker, Green Map, Seller Badge engine, Green Receipt template.
- Produce in-branch materials + **Challenge Station kits ×36**.
- **Train branch staff** (GoGreen Plus one-liner + how to run the buffet).
- Stand up the **cap-tracking system** (quota can't be exceeded) + run the **baseline awareness survey**.
- **✅ Gate:** all 36 branches kitted + cap system live + staff trained *before* launch.

### 🟢 Month 2 — Launch (Drive participation) · ฿2.8M (56%)
- Go live across **36 branches**; targeted ads to Micro-SMEs + students.
- Run the **PUT BOX buffet** (Mon & Fri · 14:00–18:00 · ASEAN · 1 per customer).
- Drive GoGreen Plus opt-ins + #hashtag UGC; Impact Wall live in every branch.
- **✅ Gate (Week 8 review):** opt-in & redemption on pace; **kill-switch** if the buffet quota is burning too fast.

### 🔵 Month 3 — Post-launch (Retain & prove) · ฿1.0M (20%)
- Retention nudges via LINE; monthly impact emails; Badge/Certificate push.
- **Post survey + system-data pull + social sentiment + SME interviews.**
- **ROI readout:** awareness lift · opt-in lift · CO₂ enabled · earned reach.

## 6. PUT BOX BUFFET — operational setup (the unique mechanic)
- **Frame:** 40 × 50 cm (height free; bigger box → higher tier via chargeable weight).
- **Tiers:** S ฿990 (1:00) · M ฿2,500 (1:30) · L ฿5,000 (2:30).
- **Bounds:** ASEAN-only · 1 box/customer · **hard cap (~4,800 boxes / while quota lasts)**.
- **Why bounded:** quantity cap → DHL exposure can't overrun; the experience stays "stuff the box" fun.
- **Staff flow:** customer packs against timer → staff takes over → real GoGreen Plus shipment → Green Receipt.
