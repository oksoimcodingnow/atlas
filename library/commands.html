The gotchas (errors you'll hit)

Every one of these has a one-line fix. None of them mean anything is broken.
'C:/atlas' is not recognized as an internal or external command
Fix: you typed a bare path. Put cd in front: cd C:\Users\HOME\atlas
scripts\review.bat — The system cannot find the path specified
Fix: you're not inside the repo. Run cd C:\Users\HOME\quant first, then the script.
The token '&&' is not a valid statement separator
Fix: PowerShell doesn't use &&. Use ; instead, or just put each command on its own line.
404 — File not found (right after you pushed)
Fix: not broken — GitHub Pages is still building. Wait ~30s, then hard-refresh with Ctrl+Shift+R.
running scripts is disabled on this system (.ps1)
Fix: use the .bat version (e.g. scripts\review.bat), which sidesteps the policy.
