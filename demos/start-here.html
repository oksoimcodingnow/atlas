Quickstart · 5 minutes

Run the handshake.

The Claude × Codex review protocol, as the keystrokes you actually type. No theory — that's in the Field Manual.

Done once per repo, then once per commit. That's it.
00
One-time setup

Wire the commit template.

Tells git to open the editor with the ### Verify block pre-filled. Do this once per cloned repo and never again. 

cd C:\Users\HOME\atlas
git config commit.template .gitmessage

cd C:\Users\HOME\quant
git config commit.template .gitmessage

If you only use these repos from inside Claude Code (where commits use full inline messages), you can skip this. The template is for manual commits.

01
Claude builds

A commit lands with a ### Verify block.

Either Claude (or you) ships a commit. The message ends with a block of 3–6 falsifiable checks — concrete things that can be true or false. 

### Verify
- [ ] No look-ahead bias — entries shift(1) before signal
- [ ] Fees + slippage present in Portfolio.from_signals
- [ ] No new deps in requirements.txt

Bad checks: "looks good", "performant", "well-documented." Good checks are testable from the diff alone.

02
You run the script

A prompt prints, ready to paste.

Open PowerShell, cd into the repo the commit landed in, and run scripts\review.bat. It reads the latest commit's subject + SHA, builds a Codex-ready prompt, and prints it. 

cd C:\Users\HOME\atlas
scripts\review.bat

The .bat bypasses Windows' default PowerShell execution policy so the script just runs — no setup needed.

03
Hand to Codex

Copy. Paste. Wait.

Copy everything between the ─── separator lines. Open your Codex session in another window or tab. Paste. Send.

Codex reads the diff with git show <sha>, walks each ### Verify item, and replies with a verdict per item plus any issues it spots outside the checklist.

04
Read the verdicts

Three things you might see.

Codex returns one of three verdicts per item:

PASS

Check confirmed in the diff. No action needed.

FAIL

Check violated. Real bug, fix required. Tell Claude.

NOTE

True but minor — Codex is flagging context, not blocking.

05
Decide

You are the only merger.

All PASS? Push / merge. Move on. No file needs to be saved.

Any FAIL? Save Codex's output to REVIEWS/2026-05-30-1430-<subject>.md and tell Claude "fix item 2 and 4 from REVIEWS/...". Claude addresses each in a new commit — never amends.

Neither agent touches main on its own. Both write code; you alone push.

06
When to skip

Discipline beats ceremony.

Use the handshake on:

  • alpha logic, risk math, anything money-handling
  • security code, auth flows, anything with credentials
  • contract changes (API shape, schema, config keys)

Skip on:

  • typos, docs, comment-only edits
  • hotfix one-liners you're confident about
  • WIP commits inside a feature branch (run it on the branch tip)

That's the workflow.

Repeat for every meaningful commit. The discipline compounds; the ceremony fades.
