1 · The Handshake

Claude builds, Codex checks, you decide. Nothing reaches main without you.
flowchart TD
    A([Start]) --> B["Claude: build the feature"]
    B --> C["Commit with a Verify block
(3–6 falsifiable checks)"]
    C --> D["Run scripts/review.bat"]
    D --> E["Paste the prompt into Codex"]
    E --> F["Codex checks each Verify item"]
    F --> G["Codex writes a REVIEWS file
PASS · FAIL · NOTE"]
    G --> H{"Owner reads
the review"}
    H -->|all PASS| I["Merge / push"]
    H -->|any FAIL| J["Claude fixes in a NEW commit"]
    J --> D
    I --> K([Done])
    classDef build fill:#1a1a3e,stroke:#818cf8,color:#f1efe6;

    class E,F,G check
    class H,I owner
