A working protocol for two agents and one owner. Claude builds. Codex checks. You decide what merges.

01
Build

Commit with a checklist.

Claude writes the code and ships a commit. The message includes a ### Verify block — three to six specific, falsifiable checks. Not “looks good.” Things that can be true or false.

git config commit.template .gitmessage

◆ ◇ ◆
02
Open the prompt

A single line, then a script.

From inside the repo, run the wrapper. It prints a Codex-ready prompt — already filled with the commit SHA, the subject, and the path the review should be written to. No retyping.

scripts\review.bat

◯ → ◉
03
Hand to Codex

Paste. Wait. Read.

Codex reads the diff, walks each item, and answers PASS · FAIL · NOTE with one sentence of evidence per call. No essays. No politeness. Just verdicts you can act on.

⌘ ⌥ ⏎
04
Decide

You are the only merger.

Read the review. All PASS — merge it. Any FAIL — hand back to Claude with the specific items to fix. Neither agent touches the main branch on its own. Authority stays with the owner.

▲ ▼
05
Re-build

A new commit, never an amend.

Claude addresses every FAIL in a fresh commit. The audit trail stays clean — anyone can read the conversation between agent and checker in the git log.

→ → →
06
Loop

Use it where it matters.

Risky work — alpha logic, money handling, security boundaries — gets the full handshake. Cosmetic commits, docs, one-line hotfixes don't. Discipline beats ceremony.
