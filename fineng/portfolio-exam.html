01Returns

A return is a percentage gain. The one-period (holding-period) return:

R = ( P₁ − P₀ + D ) / P₀
# end price − start price + dividend, over start price

Expected return of a portfolio

Just the weighted average of the assets' expected returns:

E(R_p) = Σ wᵢ · E(Rᵢ) (weights wᵢ sum to 1)

Arithmetic vs geometric

  • Arithmetic mean = simple average of periodic returns. Used as the expected return going forward.
  • Geometric mean (CAGR) = the actual compounded growth rate. Always ≤ arithmetic. Used to describe realised performance.
annualise monthly: E(R)_year = E(R)_month × 12 (returns scale linearly)
Trap

Returns scale by ×12, but risk (SD) scales by ×√12. Mix these up and every downstream number is wrong.

02Risk = variance / standard deviation

Variance measures how far returns swing from their mean. Standard deviation (SD) = √variance, in the same units as return.

σ² = Σ (Rᵢ − R̄)² / N ← population (÷N)
σ² = Σ (Rᵢ − R̄)² / (N−1) ← sample (÷N−1)
SD = σ = √σ²
Population vs sample

Your project uses population SD (Excel STDEVP, ÷N) because the prof defines the 5-year window as the whole relevant dataset. Sample (÷N−1) is only slightly larger. Know which one the question wants.

annualise SD: σ_year = σ_month × √12

03Covariance & correlation

Covariance = do two assets move together (+) or opposite (−)? Correlation = the same idea, rescaled to −1…+1 so it's comparable.

Cov(A,B) = σ_AB = Σ (R_A−R̄_A)(R_B−R̄_B) / N
Corr(A,B) = ρ_AB = σ_AB / (σ_A · σ_B) # −1 to +1
Why it's the heart of it all

Low correlation is the fuel of diversification. The lower ρ between your assets, the more risk cancels when you combine them. ρ = +1 → no diversification benefit at all.

04Two-asset portfolio

The exam loves this. Two assets A and B with weights w and (1−w):

Return: E(R_p) = w·E(R_A) + (1−w)·E(R_B)

Variance: σ²_p = w²σ²_A + (1−w)²σ²_B + 2·w(1−w)·σ_AB
# the last term uses covariance; = 2·w(1−w)·ρ_AB·σ_A·σ_B

SD: σ_p = √σ²_p

Minimum-variance weight (2-asset)

w*_A = ( σ²_B − σ_AB ) / ( σ²_A + σ²_B − 2σ_AB )
Trap

The covariance term is added and it can be negative (if ρ<0), which lowers portfolio risk below either asset alone. Don't drop the "2·" in front, and don't forget to square the weights.

05Diversification (n assets)

For an equally-weighted (naïve, 1/n) portfolio, total variance splits into two pieces:

σ²_p = (1/n)·σ̄² + ((n−1)/n)·σ̄_ij
↑ avg variance term ↑ avg covariance term
  • First term (avg variance ÷ n) → shrinks to 0 as n grows. This is the diversifiable (unsystematic) part.
  • Second term → rises toward the average covariance. This is the undiversifiable (systematic) part — the floor you can't remove.
Your portfolio

With your 10 stocks, diversifiable risk fell from ~83% of total (at n=2) to ~36% (at n=10), while undiversifiable rose from ~17% to ~64%. Total risk fell and levelled off at the average covariance — exactly the ch4 story.

One-liner

"As you add stocks, portfolio risk falls toward the average covariance — you can diversify away company risk, never market risk."

Key insight

CAPM pays you only for systematic risk (β). Bearing unsystematic risk earns nothing extra — you could have diversified it away for free. And note: 1 − R² gives the unsystematic share, and it is algebraically identical to the variance/covariance method.

07Beta

Beta = how much a stock moves when the market moves. β=1 moves with the market; β>1 amplifies; β<1 dampens.

βᵢ = Cov(Rᵢ, R_M) / Var(R_M) (= slope of stock-vs-market regression, Excel SLOPE)
Portfolio beta = Σ wᵢ·βᵢ # just the weighted average of the betas
Trap

Beta is a weighted average across a portfolio, but variance is not (variance needs the covariance terms). Only beta averages simply.

08CAPM & the SML

The Capital Asset Pricing Model gives the return an asset should earn for its systematic risk:

E(Rᵢ) = R_f + βᵢ·( E(R_M) − R_f )
required = risk-free + beta × market risk premium
  • R_f = risk-free rate (your project: 1.57%, Thai 5-yr govt bond, ThaiBMA).
  • E(R_M) − R_f = equity risk premium (your project: 7%, Damodaran Thailand).
  • SML (Security Market Line) = the plot of E(R) against β. Every fairly-priced asset sits on it. Above the line = underpriced (buy); below = overpriced (sell).
Jensen's alpha = actual return − CAPM required return
# positive alpha = beat the model = skill (or luck)
SML vs CML — don't confuse them

SML: x-axis = beta (systematic risk), applies to any asset. CML: x-axis = total SD, applies only to efficient portfolios. Different x-axis, different scope.

09Efficient frontier · MVP · Tangency

Plot every possible portfolio as a dot (x = risk, y = return). The upper-left edge is the efficient frontier — the best return for each risk level.

  • Minimum-Variance Portfolio (MVP) — the leftmost point (lowest possible risk). Objective: minimise wᵀΣw s.t. Σw=1.
  • Tangency portfolio — the point where a line from R_f just touches the frontier. It has the highest Sharpe ratio — the "optimal risky portfolio." Objective: maximise (Rᵖ−R_f)/σᵖ.
  • Efficient = on the upper edge. Anything below/inside is dominated (worse return for the same risk).
Constraint matters

Unconstrained optimisation allows short-selling (negative weights). Long-only forbids it (w ≥ 0, via Solver). Your project uses long-only, so no negatives. Same objective, one extra constraint.

10CAL / CML & the Sharpe ratio

The Capital Allocation Line (CAL) is the straight line from the risk-free asset through a risky portfolio. Its slope = the Sharpe ratio.

Sharpe = ( E(Rᵖ) − R_f ) / σᵖ # return per unit of total risk
  • The CML (Capital Market Line) is the special CAL that runs through the tangency portfolio — the steepest possible line, the best risk-return trade-off available.
  • Higher Sharpe = steeper CAL = a better deal. It's the single best "is this portfolio good?" number.
Combining with the risk-free asset

Any point on the CAL = mix of R_f and the risky portfolio. Left of the tangency point = lending (holding some cash); right of it = borrowing (leverage). The risky mix stays the same — you just change how much cash vs. risky you hold.

11Market efficiency (ch3)

The Efficient Market Hypothesis: prices already reflect available information, so you can't consistently beat the market. Three forms:

FormPrices reflect…So you can't profit from…
Weakpast pricestechnical analysis (charts)
Semi-strongall public infofundamental analysis on public data
Strongall info, incl. privateeven insider info

Anomalies (evidence against EMH): the P/E effect (low-P/E stocks beat), P/BV / value effect, size effect (small caps beat), January effect, momentum.

Concept-Q gold

If markets are semi-strong efficient, then researching public financials won't beat the market — but you also can't lose systematically. It's an argument for passive/diversified investing.

12Theory of choice & risk aversion (ch1)

  • Risk-averse investor: prefers less risk for the same return; needs a premium to take on risk. (This is the standard assumption.)
  • Utility: a common form is U = E(R) − ½·A·σ², where A = risk-aversion coefficient. Higher A → penalise risk more → hold safer portfolios.
  • Indifference curves: combinations of risk/return giving equal utility. Steeper curves = more risk-averse. The best portfolio = where the highest indifference curve touches the CAL.
Optimal risky/cash mix: w* = ( E(R_p) − R_f ) / ( A · σ²_p ) # more risk-averse (big A) → less in the risky portfolio

★Mock exam

Try each before opening the answer. Bring a calculator; the numbers are round-ish on purpose.

Q1 · concept

Define systematic and unsystematic risk, and state which one CAPM rewards. Give one real example of each.

Answer

Systematic = market-wide, undiversifiable risk (e.g. an interest-rate hike). Unsystematic = company-specific, diversifiable risk (e.g. a product recall). CAPM rewards only systematic risk (measured by beta), because unsystematic risk can be diversified away for free.

Q2 · calc · returns

A stock rises from ฿40 to ฿44 and pays a ฿2 dividend. What's the holding-period return?

Answer
R = (44 − 40 + 2)/40 = 6/40 = 15%
Q3 · calc · 2-asset

Assets A (E(R)=10%, σ=20%) and B (E(R)=16%, σ=30%), correlation ρ=0.2, weights 50/50. Find the portfolio return and SD.

Answer
E(R_p) = 0.5·10 + 0.5·16 = 13%

σ_AB = ρσ_Aσ_B = 0.2·0.20·0.30 = 0.012
σ²_p = 0.5²·0.20² + 0.5²·0.30² + 2·0.5·0.5·0.012
= 0.010 + 0.0225 + 0.006 = 0.0385
σ_p = √0.0385 = 19.6%

Note the SD (19.6%) is below the simple average of 25% — that's the diversification benefit from ρ<1.

Q4 · calc · beta & CAPM

R_f = 1.57%, market premium = 7%. A stock has β = 1.3. What return does CAPM require? If it actually returned 12%, what's Jensen's alpha?

Answer
CAPM = 1.57% + 1.3·7% = 1.57 + 9.10 = 10.67%
alpha = 12% − 10.67% = +1.33% (beat the model)
Q5 · concept · EMH

Under semi-strong efficiency, can you beat the market by studying a company's published financial statements? Explain.

Answer

No. Semi-strong efficiency means prices already reflect all public information, including published financials — so fundamental analysis on public data gives no edge. (You'd need private/inside info, and that's the strong form.)

Q6 · calc · Sharpe

A portfolio returns 16% with SD 17%. R_f = 1.57%. What's its Sharpe ratio? What does it represent geometrically?

Answer
Sharpe = (16 − 1.57)/17 = 14.43/17 = 0.85

It's the slope of the CAL — return earned per unit of total risk. Higher = steeper line = a better risk-return deal.

Q7 · calc · systematic split

A stock has total variance 0.09 and R² (vs the market) of 0.30. Split its risk into systematic and unsystematic variance.

Answer
Systematic = R²·total = 0.30·0.09 = 0.027
Unsystematic = (1−R²)·total = 0.70·0.09 = 0.063

So 30% of its risk is market-driven, 70% is company-specific (diversifiable).

Q8 · concept · frontier

What is the tangency portfolio, and why is it special? How does it differ from the minimum-variance portfolio?

Answer

The tangency portfolio is where a line from the risk-free rate just touches the efficient frontier — it has the highest Sharpe ratio, so it's the optimal risky portfolio (every investor should hold this mix of risky assets, then adjust risk with cash/leverage). The MVP is the lowest-risk point on the frontier — it minimises variance regardless of return, so it usually has a lower Sharpe than the tangency.

Q9 · calc · diversification

Average single-stock variance = 0.008, average covariance = 0.002. For a naïve 10-stock portfolio, find total variance and the % that is undiversifiable.

Answer
Total = (1/10)·0.008 + (9/10)·0.002 = 0.0008 + 0.0018 = 0.0026
Undiversifiable share = 0.0018 / 0.0026 = 69%

As n→∞, the first term →0 and total → 0.002 (the average covariance).

Q10 · concept

Why does portfolio beta average simply (Σwᵢβᵢ) but portfolio variance does not?

Answer

Beta is a linear measure of co-movement with one factor (the market), so weighting and adding is exact. Variance involves covariances between every pair of assets (the cross terms), which don't vanish — so you must use the full wᵀΣw formula, not a simple average.

Q11 · concept · risk aversion

Two investors face the same CAL. One is more risk-averse (higher A). Who holds more of the risky portfolio, and where do they sit on the line?

Answer

The less risk-averse investor holds more of the risky portfolio (bigger w*), sitting further right on the CAL (possibly borrowing/leveraging). The more risk-averse one holds more cash, sitting left, closer to R_f. Same risky mix (the tangency) — just a different cash split.

Q12 · concept · your project

Your group used long-only optimisation. Explain what that means and why the unconstrained "tangency" had a higher Sharpe.

Answer

Long-only = weights must be ≥ 0 (no short-selling). The unconstrained version is allowed to short stocks (negative weights), which gives it more freedom and thus a mathematically higher Sharpe — but short-selling isn't permitted for us, and it over-fits the sample. Long-only is the realistic, defensible choice, so we use it even though its Sharpe is a bit lower.

!!Common traps (read the night before)

  • Returns scale ×12; SD scales ×√12. Never the same.
  • 2-asset variance: keep the 2·w(1−w)·σ_AB term, and square the weights.
  • Covariance can be negative — that lowers portfolio risk. Don't force it positive.
  • SML uses beta (any asset); CML uses total SD (efficient portfolios only).
  • Portfolio beta averages simply; portfolio variance does not.
  • Systematic share = R²; unsystematic = 1−R². They're the same as the var/cov method.
  • Sharpe uses total SD; Treynor uses beta. Don't swap the denominator.
  • Diversification removes company (unsystematic) risk only — the average covariance is the floor.
  • Know your project constants cold: R_f = 1.57% (ThaiBMA 5-yr), ERP = 7% (Damodaran), population SD, long-only.
