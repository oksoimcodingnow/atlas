1Returns

Everything starts here: how you turn a stream of prices into a single number you can compare, average, and annualize.

Holding-period (simple) return
R = (P₁ − P₀ + D) / P₀
Price change plus any dividend D, over what you paid. The everyday "how much did it go up?" number.
Log (continuously-compounded) return
r = ln(P₁ / P₀)
Used in most models because log returns add up across time (r₁+r₂+…) and are roughly symmetric. For small moves, r ≈ R.
Multi-period cumulative return
R_cum = (1+R₁)(1+R₂)…(1+R_n) − 1
Returns compound, they don't add — chaining is multiplicative because each period grows the previous balance.
Arithmetic vs geometric mean
R̄_arith = (1/n)Σ Rᵢ   ·   R̄_geo = [∏(1+Rᵢ)]^(1/n) − 1
Arithmetic = simple average (expected next-period return). Geometric = the constant rate that reproduces the actual end wealth; always ≤ arithmetic, and the honest measure of realized growth.
Annualizing
R_ann = (1 + R_period)^m − 1   ·   μ_ann ≈ μ_daily × 252
m = periods per year (12 monthly, 252 trading days). Scale returns by the number of periods.
Expected return (probability-weighted)
E[R] = Σ pᵢ Rᵢ
Each possible outcome times its probability. The forward-looking version, from scenarios rather than history.
Portfolio expected return
E[R_p] = Σ wᵢ E[Rᵢ] = wᵀμ
The one part of portfolio math that's just a weighted average — return has no diversification magic; only risk does.
Real return (Fisher)
1 + R_real = (1 + R_nominal) / (1 + i)
Strips out inflation i. Approx: R_real ≈ R_nominal − i.
Time-weighted vs money-weighted performance
TWR = ∏(1+R_sub) − 1  ·  MWR solves Σ CFₜ/(1+IRR)ᵗ = 0
TWR removes the effect of deposits/withdrawals (judges the manager); MWR/IRR is the dollar-weighted return you actually earned (judges your timing).

2Risk & co-movement

How much a return bounces (variance/volatility), and how two assets move together (covariance/correlation) — the raw material of diversification.

Variance & standard deviation (volatility)
σ² = (1/n) Σ (Rᵢ − μ)²  ·  σ = √σ²
Average squared distance from the mean. Sample version divides by n−1. σ (volatility) is in the same units as returns, so it's what everyone quotes.
Annualizing volatility
σ_ann = σ_daily × √252
Risk scales with the square root of time, not linearly — because variance adds, and σ is its square root.
Covariance
Cov(A,B) = (1/n) Σ (R_Aᵢ − μ_A)(R_Bᵢ − μ_B)
Do A and B tend to be above/below their means at the same time? Positive = move together. Units are ugly (return²), which is why we normalize it →
Correlation
ρ_AB = Cov(A,B) / (σ_A σ_B)
Covariance rescaled to [−1, +1]. −1 perfect opposite, 0 unrelated, +1 identical. This single number drives the whole diversification story.
Downside deviation & semivariance downside
σ_down = √[ (1/n) Σ min(Rᵢ − τ, 0)² ]
Volatility that counts only returns below a target τ (often 0 or R_f). Punishes losses, ignores upside swings — feeds the Sortino ratio.
Coefficient of variation
CV = σ / μ
Risk per unit of return — a quick "how bumpy per point of gain" comparison across assets.

3Two-asset portfolio

The heart of Markowitz, and the case you can do by hand. This is the interactive frontier page, written out.

Portfolio return
E[R_p] = w_A E[R_A] + w_B E[R_B], w_B = 1 − w_A
Portfolio variance — the key formula
σ²_p = w_A²σ_A² + w_B²σ_B² + 2 w_A w_B σ_A σ_B ρ_AB
The last term carries the whole benefit: whenever ρ < 1, it's smaller than the weighted average, so σ_p < weighted-average σ. That gap is diversification.
Same thing, using covariance
σ²_p = w_A²σ_A² + w_B²σ_B² + 2 w_A w_B Cov(A,B)
Minimum-variance weight (closed form)
w_A* = (σ_B² − ρ σ_A σ_B) / (σ_A² + σ_B² − 2 ρ σ_A σ_B)
Set the derivative of σ²_p to zero and solve: the single mix with the lowest possible risk. Depends only on risks and correlation — not on expected returns.
Special cases worth memorizing. ρ = +1 → σ_p is just the weighted average (no benefit, frontier is a straight line). ρ = −1 → you can build a zero-risk portfolio at w_A = σ_B/(σ_A+σ_B). ρ = 0 → σ²_p = w_A²σ_A² + w_B²σ_B². Real assets sit in between.

4N-asset portfolio matrix form

Two assets generalize to any number using vectors and the covariance matrix Σ. This is what a computer actually runs.

Expected return
E[R_p] = wᵀμ = Σ wᵢ μᵢ
Variance (quadratic form)
σ²_p = wᵀ Σ w
The compact version of the double sum below — w is the weight vector, Σ the covariance matrix. One line captures every pairwise interaction.
Variance (double sum, written out)
σ²_p = Σᵢ Σⱼ wᵢ wⱼ σᵢ σⱼ ρᵢⱼ = Σᵢ Σⱼ wᵢ wⱼ Covᵢⱼ
Diagonal terms (i=j) are each asset's own variance; off-diagonal terms are the co-movements. For n assets there are n variances and n(n−1) covariance terms — covariances dominate as n grows.
Weights constraint
Σ wᵢ = 1 (wᵀ𝟙 = 1)
Fully invested. Allowing wᵢ < 0 means short-selling; "long-only" adds wᵢ ≥ 0.
Covariance from the correlation matrix
Σ = D · C · D, D = diag(σ₁…σ_n), C = correlation matrix
How you rebuild the covariance matrix Σ from volatilities and correlations — the two things you actually estimate.

5Diversification measures

Holding many names isn't the same as being diversified. These quantify how much diversification you actually get, and where the risk really sits.

Diversification ratio
DR = (Σ wᵢ σᵢ) / σ_p
Weighted-average stand-alone risk ÷ actual portfolio risk. 1.0 = no benefit (all correlated); higher = more benefit. A perfectly uncorrelated equal-vol basket reaches √n.
Effective number of bets
N_eff = 1 / Σ wᵢ²  (concentration)  ·  N_eff ≈ N / [1 + (N−1) ρ̄]  (correlation)
The first form catches weight concentration (equal weights → N). The second catches correlation concentration: ten names at ρ̄ = 0.25 behave like ~3 independent bets.
Average pairwise correlation
ρ̄ = [2 / (N(N−1))] Σᵢ<ⱼ ρᵢⱼ
Mean of the off-diagonal correlation entries — the single headline "how correlated is this basket?" number.
Marginal & component risk contribution
MRCᵢ = (Σw)ᵢ / σ_p · RCᵢ = wᵢ · MRCᵢ · Σ RCᵢ = σ_p
MRC = how much σ_p rises if you add a sliver of asset i. RC = that asset's actual share of total risk. They sum exactly to σ_p, so you can say "this name is 30% of my risk."
Equal-weight variance decomposition
σ²_p = (1/N) σ̄² + (1 − 1/N) Cov̄
As N → ∞ the first term vanishes and σ²_p → average covariance: idiosyncratic risk diversifies away, systematic (shared) risk never does. This is why ~15–20 names capture most of the benefit.
The trap. Diversification is about correlation structure, not count. Fifty stocks that all load on one factor (all Thai tourism, all US tech) give you far fewer effective bets than their number suggests — and correlations rise in a crisis, right when you need the benefit most.

6Efficient frontier · CML · CAL

From the cloud of possible portfolios to the optimal edge, then adding a risk-free asset to get the best achievable line.

Global minimum-variance portfolio
w_gmv = Σ⁻¹ 𝟙 / (𝟙ᵀ Σ⁻¹ 𝟙)
The lowest-risk point of the whole frontier. Needs only Σ — no return forecasts — so it's the most estimation-robust portfolio there is.
Tangency (max-Sharpe) portfolio
w_tan = Σ⁻¹ (μ − R_f 𝟙) / [ 𝟙ᵀ Σ⁻¹ (μ − R_f 𝟙) ]
The risky mix with the highest Sharpe ratio — where a line from R_f just touches the frontier. Combined with the risk-free asset it beats every point on the plain frontier.
Capital Market Line (CML)
E[R_p] = R_f + [ (E[R_m] − R_f) / σ_m ] · σ_p
The best risk/return line when everyone holds the market + risk-free asset. Slope = the market's Sharpe ratio (the "price of risk"). Only for efficient portfolios.
Capital Allocation Line (CAL)
E[R_c] = R_f + [ (E[R_p] − R_f) / σ_p ] · σ_c
Same idea for any risky portfolio p, not just the market — how return scales as you split money between p and the risk-free asset.
Optimal risky/safe split (mean-variance utility)
U = E[R] − ½ A σ² · y* = (E[R_p] − R_f) / (A σ_p²)
A = your risk-aversion. y* = fraction to put in the risky portfolio; the rest goes risk-free. More edge or less risk → hold more risky; more aversion → hold less.
Two-fund separation
any efficient portfolio = mix of ( GMV , tangency )
Every point on the efficient frontier is a blend of just two funds — the theoretical basis for "hold the market index + cash."

7CAPM & factor models

Splitting a return into the part explained by the market (systematic) and the part that isn't (idiosyncratic), then pricing the systematic part.

Beta
βᵢ = Cov(Rᵢ, R_m) / σ²_m = ρᵢₘ · (σᵢ / σ_m)
Sensitivity to the market. β = 1 moves with it, β > 1 amplifies, β < 1 dampens. The only risk CAPM says you're paid for.
CAPM / Security Market Line
E[Rᵢ] = R_f + βᵢ (E[R_m] − R_f)
Fair expected return for a given beta. (E[R_m]−R_f) is the market risk premium. Points above the line are "cheap," below are "rich."
Portfolio beta
β_p = Σ wᵢ βᵢ
Betas do average linearly (unlike variance) — so portfolio market-risk is a simple weighted sum.
Single-index model & risk split
Rᵢ = αᵢ + βᵢ R_m + εᵢ → σ²ᵢ = βᵢ² σ²_m + σ²_ε
Total risk = systematic (βᵢ²σ²_m, undiversifiable) + idiosyncratic (σ²_ε, diversifies away). The whole case for diversification in one line.
R² — how much is systematic
R²ᵢ = βᵢ² σ²_m / σ²ᵢ = ρ²ᵢₘ
Share of an asset's variance explained by the market. High R² → market-driven; low → mostly its own story.
Jensen's alpha
α = R_p − [ R_f + β_p (R_m − R_f) ]
Return earned above what CAPM says the beta deserved. Positive α = genuine skill (or luck — test it).
APT / multi-factor
E[Rᵢ] = R_f + Σ_k βᵢₖ λ_k
Generalizes CAPM to many risk factors, each with its own premium λ_k (rates, credit, inflation, size, value…).
Fama–French 3-factor
Rᵢ − R_f = αᵢ + b·(R_m−R_f) + s·SMB + h·HML + εᵢ
Adds size (SMB = small−big) and value (HML = high−low book/price) to the market factor. The workhorse empirical model; a 5-factor version adds profitability + investment.

8Risk-adjusted performance

Return alone means nothing without the risk taken to get it. These are how you actually compare two portfolios or managers.

Sharpe ratio
S = (R_p − R_f) / σ_p
Excess return per unit of total risk. The universal scoreboard. Annualize by ×√(periods).
Sortino ratio
Sortino = (R_p − R_f) / σ_down
Like Sharpe but only penalizes downside volatility — kinder to strategies whose "risk" is mostly big up-moves.
Treynor ratio
T = (R_p − R_f) / β_p
Excess return per unit of market risk (beta). Use when the portfolio is one slice of a bigger diversified whole.
Information ratio & tracking error
IR = (R_p − R_b) / TE, TE = σ(R_p − R_b)
Active return over a benchmark ÷ how much you wobble around it. The measure of skill relative to an index.
M² (Modigliani risk-adjusted)
M² = R_f + S_p · σ_m
Re-levers the portfolio to the market's volatility so you can compare in plain return-percent terms.
Calmar ratio & maximum drawdown
MDD = min_t ( V_t / max_{s≤t} V_s − 1 ) · Calmar = R_ann / |MDD|
MDD = the worst peak-to-trough fall (the loss that makes people quit). Calmar rewards return per unit of that pain.
Up / down capture
Capture = R_p(regime) / R_b(regime)
Share of the benchmark's up-moves you catch vs. down-moves you suffer. Ideal: high up, low down.

9Value-at-Risk & tail risk

"How bad is a bad day/month?" — the forward-looking loss numbers a risk desk lives by.

Parametric (normal) VaR
VaR_α = ( z_α σ − μ ) · V
Assumes normal returns. z_α = 1.645 at 95%, 2.326 at 99%. V = portfolio value. "With 95% confidence, you won't lose more than VaR."
Historical VaR
VaR_α = − percentile_(1−α) ( historical returns ) · V
No distribution assumed — just read the loss at the α-quantile of what actually happened. Captures fat tails the normal model misses.
Conditional VaR (Expected Shortfall)
CVaR_α = E[ loss | loss > VaR_α ]
The average loss in the worst (1−α) of cases — answers "if it's a bad day, how bad on average?" Coherent where VaR isn't.
Time scaling
VaR_T = VaR_1 · √T
Same √-of-time rule as volatility — a 10-day VaR ≈ 1-day VaR × √10 (assuming independence).

10Worked example — a real portfolio

The formulas above, run on real Thai data: a wellness-tourism basket, equal-weighted, ~4 years of daily adjusted closes. This is the analysis behind the group project — the numbers are live, not made up.

MetricFormula usedValue
Avg pairwise correlation ρ̄§50.25
Diversification ratio DR§51.74

Portfolio volatility σ_p§4 · wᵀΣw18.6%
Annualized return§1+0.6%
Sharpe ratio§8−0.07
Max drawdown§8−45%
What the formulas reveal. Average correlation is only 0.25 and DR = 1.74 — so on paper the basket spreads company-specific risk well. But N_eff = 3.1 of 10 (the correlation form in §5) exposes the truth: all ten names share the Thai-tourism factor, so they act like ~3 independent bets. And every §8 performance number is red — the theme was flat-to-down for four years. The lesson the math delivers: a single-theme portfolio can diversify company risk yet stay fully exposed to the theme's own factor risk. Diversification measured the risk correctly; it just couldn't remove what was systematic to the theme.

Symbols

R, r — simple return, log return
P₀, P₁, D — start price, end price, dividend
μ, E[·] — mean / expected value
σ, σ² — volatility, variance
Cov, ρ — covariance, correlation
w, wᵢ — portfolio weights (Σwᵢ = 1)
Σ — covariance matrix · 𝟙 — vector of ones
R_f, R_m — risk-free, market return
β, α — market sensitivity, excess return
A — risk-aversion coefficient
z_α — normal quantile (1.645 @95%, 2.326 @99%)
N, m, T — # assets, periods/year, horizon
Two rules that tie it all together. ① Returns average (wᵀμ); risk does not — variance needs the full wᵀΣw because of covariances. ② Time scales returns linearly but risk by √T. Almost every formula above is a consequence of those two facts.
